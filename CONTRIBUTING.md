# Contribution Guide

Thank you for considering contributing to the EXAMPLE PROJECT project!
We welcome contributions from everyone. Please follow these guidelines to ensure
a smooth contribution process.

## How to Contribute

1. **Fork the Repository**:
2. **Create a Branch**: Create a new branch for your feature or bug fix.
3. **Make Changes**: Implement your changes in the code-base and add yourself to the list
   of contributors in the `CONTRIBUTORS.md` file in the root of the project. By doing this
   you accept the conditions from this contribution guide.
4. **Commit Changes**: Commit your changes with a clear and descriptive commit message.
5. **Push Changes**: Push your changes to your forked repository.
6. **Submit a Pull Request/Merge Request**: Go to the EXAMPLE PROJECT repository.
   Provide a detailed description of your changes and any related issues.

## Code Style Guide

The project uses Python and should follow the guidelines described in PEP8,
see [https://peps.python.org/pep-0008/](https://peps.python.org/pep-0008/) for
details.

## AI Agentic Coding

AI generated contributions will be accepted, but they need a human review before. This
review had mentioned in the latest commit in the pull/merge request. Contributions
that seem purely AI generated will be ignored.
